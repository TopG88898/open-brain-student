# Context Map

## Contexts

- [People](./.claude/skills/people/CONTEXT.md): a private file on each person Ethan deals with, kept current from his texts, email, meetings and notes
- [Transcribe](./.claude/skills/transcribe/CONTEXT.md): a private transcript of a voice memo, meeting, podcast or video that says who spoke each line, made on this Mac

## Relationships

- **People → Thoughts**: a thought can be tied to a Person, so what Ethan captured about someone can be found from their File
- **Transcribe → People**: a Transcript's named Speakers can each become an Interaction on that Person's File, only when Ethan says yes
